**BRIEF EXPLANATION:**

1. **`.gitignore`** — rebuild branch had none; without it the 91 MB pickle will be staged on the next `git add`. The exception `!results/dataset_inspection.json` keeps the reproducibility JSON committed while excluding transient result blobs.
2. **`scripts/inspect_datasets.py`** — reproduces *every* number in `docs/dataset_sources.md` from the raw files. It **hard-codes the paper's 5005/4982 counts** and asserts the mapping `0=benign` only if the observed `{0:5005, 1:4982}` matches. If you ever swap in a different pickle whose counts don't match, the script emits `UNRESOLVED: counts do not match paper — DO NOT TRAIN` instead of silently mislabeling. This is the single defense against the label-inversion risk I flagged.
3. It calls `PIL.Image.verify()` per Mendeley file — this is the Task 2 acceptance criterion "no unreadable/corrupted images." It does **not** decode QR (that's Task 3).
4. **`docs/dataset_sources.md`** — every sha256/size/histogram is copied from your paste, not fabricated. License is marked **UNVERIFIED IN REPO** (honest record — `find` returned no license file). Outstanding-items checklist flags the exact steps needed to upgrade the license status before manuscript submission.
5. **Mendeley size-class confound** is documented in the .md — the manuscript must record it, since a pixel-level model could shortcut on size alone.
